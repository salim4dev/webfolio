# Devspace — portfolio React

Starter portfolio React + Vite avec une identité visuelle bleu nuit / indigo / violet / cyan, des animations Motion et une structure inspirée des sections courantes d'un portfolio type DevFolio, avec une implémentation originale.

## Lancer en local

```bash
npm install
npm run dev
```

## Générer le site statique

```bash
npm run build
npm run preview
```

Le site compilé est généré dans `dist/`, adapté à un hébergement statique comme GitHub Pages ou Render Static Sites.

## Personnalisation indispensable avant publication

- Remplacer les projets de démonstration dans `src/data/projects.js` par tes vrais projets.
- Mettre à jour le texte du hero, les compétences et les services dans `src/App.jsx`.
- Remplacer `hello@example.com` par ton adresse e-mail.
- Remplacer les liens GitHub et LinkedIn génériques par tes profils.
- Ajouter tes captures d'écran réelles dans `public/` et remplacer les aperçus CSS des cartes projets si souhaité.

Aucun fichier du template DevFolio n'est inclus ; les composants et styles de ce starter ont été écrits pour ce projet.
